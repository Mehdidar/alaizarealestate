# AIZA Real Estate - Deployment Guide

This platform is built with **Node.js (Express)**, **SQLite**, and **Vanilla JS**. For a seamless experience with database persistence, we recommend deploying on **Render.com**.

## 🚀 Steps to Deploy

### 1. Initialize Git & Github
Create a private repository on Github and push your code:
```bash
git init
git add .
git commit -m "Final Al Aiza Release"
# ... follow Github prompts to push to your repo
```

### 2. Prepare Render.com
1.  **Sign up** at [Render.com](https://render.com).
2.  **New Web Service** → Connect your Github repository.
3.  **Settings**:
    -   **Runtime**: `Node`
    -   **Build Command**: `npm install`
    -   **Start Command**: `npm start`
4.  **Advanced → External Disk**:
    -   This is **REQUIRED** for SQLite persistence. 
    -   Mount Path: `/opt/render/project/src/data`
    -   Update `server.js` to point the database to this path (instructions below).

### 3. Core Environment Variables
In the Render **Environmental Variables** tab, add these:
-   `EMAIL_USER`: Your Gmail address.
-   `EMAIL_PASS`: Your Gmail App Password.
-   `ADMIN_EMAIL`: Where you want to receive lead notifications.
-   `ADMIN_PASS`: Your dashboard password (e.g., `aiza2026`).

## 💾 Database Persistence Tweak
For Render, you should update the database path in `server.js` to use the mounted disk:

```javascript
const dbPath = process.env.RENDER_DISK_PATH 
    ? path.join(process.env.RENDER_DISK_PATH, 'inquiries.db') 
    : './inquiries.db';

const db = new sqlite3.Database(dbPath);
```
